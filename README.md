# SPI EEPROM Driver (25LC040A)

C++ driver for Microchip 25LC040A SPI EEPROM.

## Отличия при работе с NOR Flash


- Перед записью в EEPROM стирание не требуется, а NOR память требует обязательного стирания перед записью.
- Стирание выполняется страницами.
- В NOR Flash при записи биты могут меняться только с 1 на 0, а для изменения бита с 0 на 1 требуется операция стирания.
- NOR Flash имеет большие страницы и большее адресное пространство.
- Операции записи и стирания занимают больше времени.
